# Download Generated Images

This example explains how to retrieve images generated by ComfyUI after a workflow completes, including querying execution history and downloading individual image files.

---

## Query Execution History

Use `GET /history` to see the output of completed prompts. Each entry contains the node outputs for that execution.

```javascript
/**
 * Retrieves the most recent execution history entries.
 *
 * @param {number} [maxItems=10] - Maximum number of history entries to return.
 * @returns {Promise<object>} History object keyed by prompt_id.
 */
async function getHistory(maxItems = 10) {
  const response = await fetch(
    `http://127.0.0.1:8188/history?max_items=${maxItems}`
  );
  if (!response.ok) throw new Error(`GET /history failed: HTTP ${response.status}`);
  return response.json();
}

// Get a specific prompt's history
async function getPromptHistory(promptId) {
  const response = await fetch(`http://127.0.0.1:8188/history/${promptId}`);
  if (!response.ok) throw new Error(`GET /history/${promptId} failed: HTTP ${response.status}`);
  return response.json();
}
```

### History entry structure

```json
{
  "<prompt_id>": {
    "status": {
      "status_str": "success",
      "completed": true,
      "messages": []
    },
    "outputs": {
      "7": {
        "images": [
          {
            "filename": "minimal_example_00001_.png",
            "subfolder": "",
            "type": "output"
          }
        ]
      }
    }
  }
}
```

## Extract Image Descriptors

```javascript
/**
 * Extracts all image descriptors from a history entry's outputs.
 *
 * @param {object} historyEntry - Single prompt entry from GET /history.
 * @returns {Array<{ filename, subfolder, type }>}
 */
function extractImages(historyEntry) {
  const images = [];
  for (const output of Object.values(historyEntry.outputs ?? {})) {
    for (const img of output.images ?? []) {
      images.push({
        filename:  img.filename,
        subfolder: img.subfolder ?? '',
        type:      img.type ?? 'output',
      });
    }
  }
  return images;
}
```

## Download an Image

Generated images are served by `GET /view` and identified by `filename`, `subfolder`, and `type`.

### JavaScript

```javascript
import { createWriteStream } from 'node:fs';
import { mkdir } from 'node:fs/promises';
import { pipeline } from 'node:stream/promises';

/**
 * Downloads a single image from the ComfyUI server.
 *
 * @param {string} filename - Filename from the history entry.
 * @param {string} [subfolder] - Subfolder inside ComfyUI's output directory.
 * @param {string} [type] - "output" for generated images, "input" for uploads.
 * @param {string} [destDir] - Local directory to save the image.
 * @returns {Promise<string>} Local file path of the downloaded image.
 */
async function downloadImage(filename, subfolder = '', type = 'output', destDir = 'output') {
  await mkdir(destDir, { recursive: true });

  const query    = new URLSearchParams({ filename, subfolder, type });
  const response = await fetch(`http://127.0.0.1:8188/view?${query}`);
  if (!response.ok) throw new Error(`GET /view failed: HTTP ${response.status}`);

  const localPath = `${destDir}/${filename}`;
  await pipeline(response.body, createWriteStream(localPath));
  console.log(`Downloaded → ${localPath}`);
  return localPath;
}
```

### C\#

```csharp
/// <summary>
/// Downloads a single generated image from the ComfyUI server.
/// </summary>
static async Task<string> DownloadImageAsync(
    HttpClient client, string filename, string subfolder = "", string type = "output")
{
    string url = $"http://127.0.0.1:8188/view"
               + $"?filename={Uri.EscapeDataString(filename)}"
               + $"&subfolder={Uri.EscapeDataString(subfolder)}"
               + $"&type={Uri.EscapeDataString(type)}";

    var response = await client.GetAsync(url);
    response.EnsureSuccessStatusCode();

    Directory.CreateDirectory("output");
    string localPath = Path.Combine("output", filename);
    await using var fs = File.Create(localPath);
    await response.Content.CopyToAsync(fs);

    Console.WriteLine($"Downloaded → {localPath}");
    return localPath;
}
```

## Batch Download All Recent Outputs

```javascript
async function downloadAllRecent(maxItems = 5) {
  const history = await getHistory(maxItems);

  for (const [promptId, entry] of Object.entries(history)) {
    const status = entry.status?.status_str;
    if (status !== 'success') {
      console.log(`Skipping ${promptId} (status: ${status})`);
      continue;
    }

    const images = extractImages(entry);
    for (const img of images) {
      await downloadImage(img.filename, img.subfolder, img.type);
    }
  }
}

downloadAllRecent().catch(console.error);
```

## Wait and Download (After Queuing)

The most reliable pattern is to monitor via WebSocket and download immediately after the `executing` event with `node: null` signals completion:

```javascript
// After WaitForCompletion resolves with nodeOutputs:
const images = extractImages({ outputs: nodeOutputs });
for (const img of images) {
  await downloadImage(img.filename, img.subfolder, img.type);
}
```
